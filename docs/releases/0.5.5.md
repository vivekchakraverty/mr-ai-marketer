# Mr. AI Marketer 0.5.5

"When to post" now works on Mastodon servers generally, rather than only on small
ones — and says how precisely it can actually answer.

---

## It works on your server, whichever that is

Measured across four servers with nothing special-cased about any of them:

| server | credential | usable answer |
|---|---|---|
| mstdn.social | none needed | best hours |
| fosstodon.org | none needed | best hours |
| mastodon.social | your own token | best 2-hour blocks |
| hachyderm.io | none needed | best days of the week |

Most of the fediverse serves the data anonymously, so no login is needed. Where a
server does require one — mastodon.social among them — it uses the access token you
entered in Settings for **that** server.

Two things were stopping this.

**Some servers answer "no posts" when they mean "not through this door."**
mastodon.social returns an empty list for the timeline the collector was reading,
which is indistinguishable from a quiet server. Its hashtag feeds work normally, so
author discovery now falls back to those.

**A credential was being sent to servers it did not belong to.** A Mastodon token is
issued by one server and is meaningless anywhere else — but sending it still hands
that server a working credential for your account, one that can post as you. Three
paths did this, including collecting every accepted server in one pass. Now a token
only ever travels to the server that issued it, checked independently at both ends,
and a server you have no account on is read anonymously instead.

Settings can now hold an account per server rather than just one, so people posting
from more than one place have the right credential for each. There is not yet a
screen for adding the second one — that is coming.

---

## It only claims the precision it has

The recommendation used to be hourly or nothing. When an hour-by-hour pattern could
not be confirmed, the whole panel went quiet — including advice the same data
supported perfectly well. That is why a busy server could report having nothing to
say.

It now tries hour-by-hour first, then two, three and four-hour blocks, and gives you
the finest answer that actually holds up. If none do, it still says nothing, but
only after asking the easier questions. The panel tells you which width it is
speaking at, and a suggested window can no longer be narrower than the evidence
behind it.

**Day of the week is judged on its own**, because it is a different question rather
than a coarser one — and the servers disagree about which is stronger. On hachyderm
the weekly rhythm is the clearer signal; on mastodon.social the time of day is.
Previously a failing hourly curve suppressed both.

---

## Upgrading

Nothing to migrate. Press **Check** on your server in the composer; the answer will
either be a real recommendation or an honest account of why not.
