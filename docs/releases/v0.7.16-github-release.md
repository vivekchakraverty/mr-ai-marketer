The Email Writer can run on your own GPU: four seconds an email instead of eighty-four.

## Added: bring-your-own Modal GPU for the Email Writer

The Email Writer's home is a free Hugging Face CPU Space, which serves a 7B model on two
shared vCPUs. Measured against the live Space, one email takes about **84 seconds**, and every
caller in the world queues behind every other. That is the price of genuinely free.

Point the tool at your own Modal workspace and the same model answers on a T4. Measured
against a real deployment rather than estimated:

| | |
|---|---|
| First-time setup (image build + 4.5 GB of weights) | 146 seconds, once |
| First email after the container wakes | 23 seconds |
| Each email after that | **4 seconds** |
| The same brief on the free Space | 84 seconds |

Set it up in Settings under **Email Writer GPU**: paste a Modal API token, press the button,
wait for the first deploy. If you have already set up Brand Studio's GPU, those credentials
are used automatically — one Modal account, and being asked for the same token twice is worse
than a default that works. The backend reads them when it starts, so restart the app after
saving.

**It is the same model, deliberately.** The same Q4_K_M GGUF the Space serves, at the same
quantisation, with the same system prompt and the same leak filter. Moving where inference
runs should not quietly change what the tool writes, so the hardware is the only variable.

**Leaving it blank changes nothing.** The Space stays the default and the fallback, because it
costs nothing and never runs out.

## What it costs, said plainly

Modal's starter plan is **$30 of credits a month, not a free tier**. A T4 bills at
$0.000164/second and containers scale to zero when idle, so a warm email is about $0.0007, a
cold one about $0.004, and the one-off setup about $0.02 — roughly forty thousand emails
inside a month's credits. That is free at any volume this tool realistically produces, but it
is credits, they can be exhausted, and they are billed to whoever's token is configured.
Set a budget cap under Modal's Usage & Billing if that matters to you.

## A choice worth knowing about

A configured GPU that fails **reports the failure** rather than quietly falling back to the
Space. Someone who set a GPU up wants to hear that it stopped working; silently taking ninety
seconds on shared CPU instead looks like the tool got slower for no reason.

## Verification

The complete backend suite passes: **296 tests**. Six are new and cover which backend runs and
why: the Space when no credentials are set, the GPU when they are, the Space when only half a
credential pair is present, a configured GPU's failure surfacing rather than being replaced,
the Hugging Face token falling back to the environment for callers that pass none — the Lead
Gen Agent drafts through this same service with an instruction and no token — and an empty
brief reaching neither backend.

Beyond the suite, the deploy path was exercised against a real Modal workspace: the app
deployed, a cold email generated, a warm email generated, and the figures above are those
measurements rather than projections.

Electron's main process and renderer pass TypeScript checking, and the production desktop
bundle builds successfully.

Not verified: the Settings button itself. The deploy was driven directly against the runtime,
so the button, its progress polling and the credential fallback are typechecked but unclicked.

## Installing

These installers are unsigned. Windows SmartScreen and macOS Gatekeeper will both warn about
that — expected, not a sign anything is wrong. On Windows choose **More info → Run anyway**;
on macOS, right-click the app and choose **Open**.
