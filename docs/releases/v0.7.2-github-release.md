A keyword run now collects the whole ideas table instead of its first page — 44 ideas where
it used to bring back 5.

**This replaces 0.7.1.** Everything in that release is here, plus the fix for the issue its
notes had to warn about. If you have not installed 0.7.1, install this instead.

## Nine times the keywords

Keyword Surfer shows its ideas five at a time behind a pager — *"1–5 of 44"* — and the
collector read only what was on screen. So a run reported **complete** having collected five
ideas out of forty-four, which is worse than looking broken: the number was right there and
nothing suggested anything was missing.

A run now widens the panel's own page-size control and then walks the pager, gathering the
whole table. Measured on the same search that produced five before:

| | Ideas collected |
|---|---|
| Before | 5 |
| After | **44** |

That is the figure your CSV export gets, and the figure the marketing plan builds its SEO
work from.

## The pager is not a keyword

Reading the whole table meant reading the controls around it too, and the page-size selector
arrived in the results as a keyword called **"per page"** with a search volume of 251,020 —
its options, `2, 5, 10, 20`, run together into a number. It looked exactly like real data and
would have gone into an export as a genuine term. Controls are now excluded.

## A finished run keeps its own result

0.7.1 warned about this and shipped a guard that did not hold. After a run ended, the feature
that collects searches you type by hand could read the run's own results page a second time
and report *"Collected 1 search you ran in the collector window"* in place of the run's
summary.

The guard failed because it recognised a run's search by its web address, and Google rewrites
that address as the page loads — so the two never matched. A run's searches are now
recognised by the search term itself, which nothing rewrites.

## From 0.7.1

Runs no longer sit waiting for a Google check that is not happening. The check was decided by
the words *"not a robot"* appearing anywhere on the page — the label on every such checkbox on
the web — and once waiting, only that phrase disappearing could end the wait. Both are fixed:
the check now looks for what only the real interstitial has, and a run carries on the moment
the figures become readable.

## Verified

Every part of this was confirmed with real Google searches before release, not only with
tests — including two attempts that looked correct and were not: the first still collected
five ideas, and the second collected forty-five, one of which was the pager.

## Installing

These installers are unsigned. Windows SmartScreen and macOS Gatekeeper will both warn about
that — expected, not a sign anything is wrong. On Windows choose **More info → Run anyway**;
on macOS, right-click the app and choose **Open**.
