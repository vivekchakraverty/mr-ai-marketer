# Mr. AI Marketer 1.0.1

This update adds separate workspaces for multiple accounts and improves Bluesky media posts.

## What's new since v1.0.0

- **Separate account workspaces:** Add, rename, and switch workspaces from the Connected accounts menu. Each workspace has its own local databases, Library, content calendar, drafts, generated files, connected-account settings, browser storage, and local engine data. Your existing installation remains in the original “My workspace”; its files are not moved.
- **Bluesky media link cards:** The Bluesky composer can detect a public media URL in post text and attach a link card automatically. YouTube links use video information and a thumbnail when available. Cards are carried through Create to Engage and Distribute, so they are included in the published post. Bluesky clients that support YouTube players can play them from the card; other clients can open the link.
- **More reliable Engage feed:** Temporary Bluesky errors are retried when loading notifications and the timeline. Notification cards still load if their extra post details fail. Feed refresh errors appear separately from posting errors, and a confirmed post provides an **Open post** link. If Bluesky cannot confirm a write, check your profile before retrying to avoid a duplicate.

## Workspace and update notes

Switching workspaces restarts the app. Local scheduled work runs only in the current workspace. Connect the platform accounts you want to use in each new workspace. Existing account credentials and content stay in the original workspace.

## Install and feedback

Download the asset for your operating system below. Windows 10/11 x64 is the primary supported desktop target; macOS and Linux packages are experimental. The installers are unsigned, so Windows SmartScreen or macOS Gatekeeper may show a warning. Review the publisher and release URL before choosing to run one.

Please report problems through [GitHub Issues](https://github.com/vivekchakraverty/mr-ai-marketer/issues), including your operating system, workspace, the tool involved, and steps to reproduce.
