# Mr. AI Marketer 1.0

This release brings audience research, content planning, and the distribution calendar into one workflow.

## What's new since v0.7.25

- **Buyer Persona:** Build evidence-based profiles from saved Align analyses, project details, and bounded public research. Reports are saved locally and can be reopened. Music and Visual Art analyses can now be saved and reused as persona sources.
- **Four-week Content Calendar:** Turn a completed Buyer Persona report and its Align signals into a sustainable channel mix and weekly topic plan. The plan uses contextual findings from DataReportal's Digital 2026 report and Pew Research Center's *Americans' Social Media Use 2025*; Pew findings are used only for U.S. markets. When Bluesky or Mastodon is in the channel mix, the calendar shows the app's measured posting-time guidance. Mastodon timing is specific to the server you choose.
- **Distribution Calendar:** Browse country and regional observances alongside scheduled posts. The calendar handles local dates and time zones when showing scheduled work.
- **Notification Center:** See generation failures and completed persona reports in one place. A diagnostic Hugging Face model test runs only after you choose to allow it.
- **Saved research continuity:** The former Audience Personas wizard has been replaced by Buyer Persona. Previously saved persona research remains available as source material, including for Marketing Plan targeting.

## Install and feedback

Download the asset for your operating system below. Windows 10/11 x64 is the primary supported desktop target; macOS and Linux packages are experimental. The installers are unsigned, so Windows SmartScreen or macOS Gatekeeper may show a warning. Review the publisher and release URL before choosing to run one.

For AI generation, configure a Hugging Face token in Settings. Public research and model requests require an internet connection. Saved reports and calendars are stored in the app's local database.

Review generated personas, channel choices, and topic ideas before using them in a campaign. Posting-time differences are small, and a Mastodon server without enough reliable data will show an explanation instead of a guessed time. Please report problems through [GitHub Issues](https://github.com/vivekchakraverty/mr-ai-marketer/issues), including your operating system, the tool involved, and steps to reproduce.
