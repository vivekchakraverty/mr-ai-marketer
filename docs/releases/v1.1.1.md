# Mr. AI Marketer 1.1.1

This update restores the macOS download, which 1.1.0 could not include, and gives Apple Silicon Macs a native media engine for the first time.

## What's new since v1.1.0

- **The macOS app is back:** Version 1.1.0 shipped for Windows and Linux only. The site the build downloaded its media tools from for macOS stopped offering automated downloads, so the macOS installer could not be built. 1.1.1 gets them from a different source and includes a macOS download again.
- **Native media tools on Apple Silicon:** DocuMaker and TutorialMaker use ffmpeg to extract audio and capture frames. On Macs it used to be an Intel-only build, which Apple Silicon Macs could run only through Rosetta 2. It is now built natively for Apple Silicon, and the build checks this so an Intel copy cannot slip back in.
- **Verified downloads:** The macOS media tools are now checked against fixed checksums recorded in the build itself, so a build fails rather than packaging a file that differs from the one that was reviewed.

Nothing changes on Windows or Linux in this release.

## Coming from v1.0.1?

This release also includes everything in 1.1.0. Most importantly, the app now recognises a *paused* cloud poster Space, which stops scheduled posts silently, instead of treating it as merely asleep. You can restart a paused Space from Settings → Cloud posting.

## Install and feedback

Download the asset for your operating system below. Windows 10/11 x64 is the primary supported desktop target; macOS and Linux packages are experimental. The installers are unsigned, so Windows SmartScreen or macOS Gatekeeper may show a warning. Review the publisher and release URL before choosing to run one.

Please report problems through [GitHub Issues](https://github.com/vivekchakraverty/mr-ai-marketer/issues), including your operating system, workspace, the tool involved, and steps to reproduce.
