## CPC, where Keyword Surfer has it

Newer versions of the Keyword Surfer extension stopped showing a CPC column in the ideas
table, so the collector — which reads what the panel displays — had nothing to read. Every
result came back with an empty CPC, including the keyword you searched for.

The extension still *loads* those figures; it just no longer draws them. They sit in the
cache it keeps in your own browser, and the collector now reads them from there to fill in
what the table no longer shows.

Measured on a real search for *leather laptop bag*:

| | Before | After |
|---|---|---|
| CPC on the searched keyword | — | **$1.99** |
| Ideas carrying a CPC | 0 | **20** |

## What it does not do

**CPC will not appear on every idea.** Keyword Surfer holds figures for the term you
searched and the ideas it fetched alongside it — in the run above, 20 of 98 rows. The rest
show a dash, which means "not published for this one", exactly as before. Nothing is
estimated or filled in from elsewhere.

The displayed table still decides which keywords belong to your result. The cache is only
ever used to restore a missing figure on a row that is already there, so an older search
sitting in the cache cannot introduce keywords you did not ask for, and figures from one
country cannot leak into a search run for another.

The collector also never asks the extension's own service for anything. It reads the panel
you can see and the records that panel already loaded — the same principle the collector has
always worked on.

## Installing

These installers are unsigned. Windows SmartScreen and macOS Gatekeeper will both warn about
that — expected, not a sign anything is wrong. On Windows choose **More info → Run anyway**;
on macOS, right-click the app and choose **Open**.
