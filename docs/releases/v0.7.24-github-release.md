Align now helps you find an audience for a creative writing work, and Distribute lets you
remove a scheduled post before it goes out.

## New: Align → Writing

Upload a TXT, Markdown, DOCX, EPUB, or text-based PDF manuscript. Writing reads the whole work
in sections and builds a profile you can review: genres, themes and central message, tone,
tropes, content intensity, comparable titles, and what readers might be looking for. It then
suggests three audience platforms with starting points for participation. These are leads for
your review, not claims that a community currently allows promotion; check its rules before
posting.

The manuscript is sent in sections to Hugging Face using the token already saved in Settings.
The upload itself is not retained. The resulting profile and audience plan are saved in the
app's existing database and can be edited later. A scanned PDF needs OCR before Writing can
read it.

## Distribute: cancel and delete scheduled posts

Send history now has a **Cancel & delete** action on posts that are still scheduled, including
posts handed to your poster Space. Confirming it removes the scheduled job from history and,
for a cloud post, removes its queued attachments as well. If sending has already begun, the
app refuses the deletion instead of saying the post was stopped. Sent posts remain in history.

## More useful analysis failures

Writing now asks Qwen3.5-9B for a direct response and retries temporary Hugging Face failures.
It starts with the least expensive listed provider for that model, then tries the other listed
providers if necessary. An error report names the section that failed, each provider and HTTP
status, any provider message, and request IDs. A 503 is reported as a provider availability
problem rather than an invalid token.

## Verification and limitations

The backend tests, Electron typechecks, and renderer build pass. Provider failures were checked
with simulated HTTP responses; a full anthology analysis against live Hugging Face providers
has not yet been verified.

The installers are unsigned. Windows SmartScreen and macOS Gatekeeper may warn when opening
them; macOS users need to download the new DMG manually because unsigned macOS auto-updates
are not supported.
