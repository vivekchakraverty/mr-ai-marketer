# Mr. AI Marketer 0.5.6

A build fix. **Nothing in the app changed** — this release exists so there is a Linux
download again.

---

## Linux builds are back

There has been no Linux artifact since 0.5.2. Every build from 0.5.3 onward failed
at the same step, and nothing in the app caused it: the site the build downloaded
ffmpeg from stopped answering. It still resolves, but refuses connections — one
maintainer's server with no mirror, so retrying was never going to help.

ffmpeg now comes from a build hosted on GitHub, which the build process already
depends on for everything else. It publishes a checksum file, and it is the same
class of build as before, so nothing about what the app ships or how it is licensed
changes.

Two problems surfaced while replacing it, both found by running the script rather
than trusting it:

- The integrity check was **quietly checking nothing useful**. A formatting slip in
  how the expected checksum line was assembled made the tool look for a file that
  did not exist, so it reported a missing file instead of a mismatch. Rebuilt from
  the hash directly.
- The binaries sit in a different place in the new archive. They are now **found by
  name** rather than assumed at a fixed path — otherwise the build would have
  succeeded while shipping a package with no ffmpeg in it, which fails much later
  and much more confusingly.

The step now runs ffmpeg once after unpacking it, so a download that succeeds but
produces something unusable fails during the build rather than on someone's machine.

**Windows and macOS builds were never affected** — they fetch from different hosts
and have been fine throughout.

---

## Note on download size

The replacement ffmpeg is larger than the old one, roughly double per binary, so the
Linux downloads are bigger than they were in 0.5.2. Worth revisiting: the Windows
build separately ships a "full" ffmpeg where a much smaller one would do.

---

## Upgrading

Nothing to migrate, and nothing new to try. If you are on Windows or macOS, 0.5.5
already contains everything in this release except the build fix.

Everything from [0.5.5](https://github.com/vivekchakraverty/mr-ai-marketer/releases/tag/v0.5.5)
still applies: posting-time recommendations now work across Mastodon servers and
report at the resolution the data actually supports.
