Keyword Surfer works in an installed copy of the app. It could not before — and this
release also fixes a quieter problem in the same tool, where a column that told you whether
to trust the numbers has been blank since the day it was added.

## The collector browser opens

Pressing **Open browser** in Keyword Surfer failed on an installed build with a message
about a missing executable. The tool drives a real Chrome-style browser, and the installer
never contained one: the browser is a separate download that the build step never ran. It
worked on the machine it was written on, because that machine had one from earlier. Nothing
about it could ever have worked on yours.

Rather than add roughly 150MB to an installer that is already 600MB–985MB, the app now
drives a browser you already have — **Microsoft Edge or Google Chrome** — falling back in
that order. It uses its own separate profile, so it does not touch your browsing, your
history or your logins. Nothing is added to the download.

If none is found, it now says so in one sentence telling you what to install, rather than
printing a developer's error message.

## The location column has never had anything in it

Every search records which location Keyword Surfer reported its figures for. That value was
being stored under one name and read under another, so nothing ever found it.

Two consequences, both invisible until you went looking:

- The **`surfer_location_detected`** column in every exported spreadsheet has always been
  empty.
- The location shown beside each keyword on screen has never appeared at all.

Both now show what was actually collected.

## Numbers for the wrong country now say so

A search volume only means anything for a place. If Keyword Surfer's own location setting is
pointing somewhere other than the region your search ran in, every figure you get back is
for the wrong country — and it looks exactly like a correct result.

Each keyword now shows both: the region searched, and the location Surfer reported for. When
they disagree, the card says plainly that the numbers are for somewhere else and what to
change.

The comparison is intentionally forgiving about spelling, because the two values come from
different places and phrase things differently. A warning that fired on every correct run
would only teach you to ignore it.

## Also

- Each search now keeps the exact address it came from, so a figure that ends up in a plan
  can be traced back to the page it was read off.
- Earlier runs list the country they ran in, not just how many keywords they covered.

## Known gap

Finished runs can be exported or sent to a marketing plan, but their figures cannot be
reopened for viewing inside the app. The data is safely on disk; there is simply no screen
for it yet.

## Installing

These installers are unsigned. Windows SmartScreen and macOS Gatekeeper will both warn about
that — expected, not a sign anything is wrong. On Windows choose **More info → Run anyway**;
on macOS, right-click the app and choose **Open**.
