The companion-image section stopped writing suggestions and quietly handed you its
fallback template every time, with a message that pointed at the wrong problem. One fix.

## Image prompt suggestions work again

Pressing **Suggest a prompt** produced the standard template and this note:

> Could not reach Qwen/Qwen2.5-7B-Instruct, so this is the standard direction.

Nothing was unreachable. Hugging Face sends each request to a provider that both serves the
model *and* is switched on for your account. The model this feature was pinned to has
exactly one working provider — and if that one is not enabled on your account, every request
is refused outright:

> The requested model is not supported by any provider you have enabled.

Which is why your post generators kept working on the same account and the same key: their
model is served by three providers, so something was always available to answer.

**It no longer depends on a single model.** The suggestion now tries three in turn, smallest
first — this is one paragraph of art direction, not an essay — falling through to the model
the post generators already rely on. In practice the first one answers and the request costs
about what it did before.

If you deliberately set `IMAGE_PROMPT_MODEL`, that still pins exactly one model with no
substitution. Naming a model means you want that model.

## And when it genuinely cannot write one

The message now names the thing you can actually do something about:

> Wrote the standard direction instead — no provider enabled on your Hugging Face account
> serves it. Edit it freely.

The old wording sent people hunting for a network problem that was never there. If you do
see this, the fix is to enable a provider in your Hugging Face account settings — and the
template it gives you is still a perfectly good starting point to edit.

## Installing

These installers are unsigned. Windows SmartScreen and macOS Gatekeeper will both warn about
that — expected, not a sign anything is wrong. On Windows choose **More info → Run anyway**;
on macOS, right-click the app and choose **Open**.
