Scheduled posts can now be cancelled safely from Send History before publishing begins.

## New: cancel a scheduled post

A red × now appears beside every row still marked **Scheduled** in Distribute → Send
History. The row shows the actual local send date and time, and choosing × asks for
confirmation that names both the channel and that scheduled time.

After a successful cancellation, the row remains in history as **Cancelled** and its
cancel control disappears. This keeps a clear record of what happened instead of making
the job vanish. Errors stay visible below Send History, the button cannot be submitted
twice while it is working, and keyboard and assistive-technology users receive visible
focus and progress feedback.

## Fixed: cancellation cannot race the scheduler

The scheduler may already have noticed that a post is due at the same moment someone
chooses to cancel it. Cancellation and the decision to begin publishing are now one atomic
choice rather than two updates that can overwrite each other.

If cancellation wins, the post is not handed to the social network even if the scheduler
saw it in an earlier snapshot. If publishing wins first, the app reports that the post is
no longer scheduled instead of falsely claiming it was cancelled. A scheduled job can also
be claimed only once, so overlapping scheduler passes cannot publish it twice.

## Limits

Cancellation is available only while a row is still marked **Scheduled**. Once it is
sending, sent, failed or waiting for approval, the scheduled-send cancellation control is
no longer available.

A multi-channel send is stored as one scheduled row per channel. Cancelling one row stops
that channel only; cancel each remaining scheduled row to withdraw the post everywhere.
There is no undo or reschedule action for a cancelled row — schedule the post again if it
is needed later.

## Installing

These installers are unsigned. Windows SmartScreen and macOS Gatekeeper will both warn about
that — expected, not a sign anything is wrong. On Windows choose **More info → Run anyway**;
on macOS, right-click the app and choose **Open**.
