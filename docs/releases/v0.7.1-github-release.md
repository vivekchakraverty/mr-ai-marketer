Keyword Surfer stopped collecting because it thought Google was blocking it, while a results
page full of numbers sat on screen. Three fixes, verified with real runs.

## Runs no longer wait for a check that is not happening

A run would park itself on:

> Google needs a manual check. Complete it in the collector browser window — this run
> resumes on its own.

…with the collector window showing an ordinary results page, Keyword Surfer's figures
already loaded. Five minutes later the keyword was recorded as **google challenge**, with no
volume, no CPC and no ideas.

Two separate causes, both fixed:

**It decided too easily that it was blocked.** The check treated any page containing the
words *"not a robot"* as a block. That is the label on every "I'm not a robot" checkbox on
the web, so any page *about* captchas contains it — and a search about plugins or AI can
easily turn one up in its results. It now looks for things only the real interstitial has:
Google's own address for it, its own wording, and the check form itself.

**Once it was waiting, only silence could end the wait.** The run watched for the block to
disappear, and nothing else — so a page that still read as blocked kept it waiting beside a
panel already full of the numbers it wanted. It now also carries on the moment the figures
become readable, which is the thing it was actually waiting for.

## A finished run no longer replaces itself

After a run ended, its last results page was still on screen — and the feature that collects
searches you run by hand saw a results page it had not recorded, filed it a second time, and
replaced the finished run with that. A one-keyword run ended up reporting *"Collected 1
search you ran in the collector window"* instead of its own result.

Searches a run performs are now claimed as its own, so only searches you actually type are
collected as yours.

## Verified, not just written

Both paths were exercised against real Google searches before this was released:

- A run completes and keeps its own results, with no phantom check and no five-minute wait.
- Searches typed by hand in the collector window are still picked up — the first time that
  has been confirmed working end to end since it was added.

## Installing

These installers are unsigned. Windows SmartScreen and macOS Gatekeeper will both warn about
that — expected, not a sign anything is wrong. On Windows choose **More info → Run anyway**;
on macOS, right-click the app and choose **Open**.
