# Mr. AI Marketer 0.5.2

Three things you can see: every post can now have an image you actually directed,
anything in the Library can be edited where it sits, and "When to post" works on
the large Mastodon servers where it previously just said no.

---

## Companion images, with the prompt in your hands

All three post creators — Bluesky, Mastodon and Tumblr — gain an image section
under the draft.

A small model reads the finished post and proposes the picture. **That proposal
lands in an editable box, and nothing is drawn until you press Generate on wording
you have read.** Change anything you like first: image models fail in specific,
correctable ways — wider shot, lose the desk, warmer light — and a minute spent on
the sentence beats regenerating five times hoping for a different result.

This replaces how the Bluesky composer worked. It built the prompt internally and
drew in one click, so the only way to change the picture was to change the post.
Mastodon and Tumblr had no image generation at all.

The refusal is enforced underneath the screen, not just by it: the endpoint rejects
a request that carries no prompt, so there is no path anywhere in the app that
renders text you never saw.

**On cost.** The suggestion runs on a small model rather than the large one the
composers use to write posts. Producing one paragraph of art direction is a short,
well-specified task, and paying composer prices for it every time you wanted a
picture would be waste you could see on your bill. If that model is unreachable or
your account cannot use it, you get the standard direction instead with a line
saying so — it is text you were going to edit anyway, and it is not worth failing
a screen over.

## The Library is editable

Everything on that shelf was read-only, and the "Open in editor" button did
nothing at all — so a saved post with a typo stayed a saved post with a typo.

Items now open into an editable box with an **Edit / Preview** toggle, and **save
themselves as you type**. There is no Save button on purpose: everything here is
already saved, so adding one would create a state the rest of the app does not
have — edited but unsaved — whose only discovery route is losing the edit by
navigating away.

Saving never reorders the shelf. It sorts by when a thing was made, and an item
climbing to the top while you were still typing into it would be its own small
bug.

If an entry has a document beside it — a Word file from Docs, say — you are
editing the saved text and the file is left alone. The screen says so. That
document belongs to the tool that produced it, and quietly rewriting one to match
the other would be a guess about which you meant.

## "When to post" now works on large Mastodon servers

It reported that no timing data had been collected for `mastodon.social`, and
pressing **Check** never changed that. The feature was not broken — it was locked
out.

The curve learns from a server's public local timeline, which is the only broad
sample of that server's own members. `mastodon.social` does not serve that timeline
to anonymous callers; it answers *"this method requires an authenticated user"*.
The app asked without logging in, took the refusal, and reported that the server
"does not serve a public local timeline" — which reads as *this server has nothing*
when the truth was *this server wants you to log in*.

It now reads that timeline as you, using the Mastodon account the composer already
publishes with, and when there is no account connected it says which to connect
rather than describing a failure. Smaller servers that do serve it anonymously
still work without a login.

Two things this does not change. The sample is still that server's own accounts
only — engagement counts are trustworthy only on the server hosting an account, so
posts that merely federated in are still excluded. And the reliability gate still
decides whether a curve ships at all: **toot.garden will keep refusing**, for an
unrelated reason no login can fix — 83 monthly members is too small a sample for
any curve to reproduce on its own data.

## Upgrading

Nothing to migrate.

- **Press Check on your Mastodon server** once, if you want a timing curve. Reading
  a month of a large instance takes a moment.
- Image sections appear under any draft you generate; nothing happens until you
  ask for a prompt.
