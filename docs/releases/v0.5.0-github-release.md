Tumblr becomes a network the app both posts from and learns from, adding a niche
now fills it instead of leaving it empty for hours, and the Mastodon exemplar
pools turned out to be partly built from posts that had failed.

## Tumblr Post Creator — new tool

The third post generator, alongside Bluesky and Mastodon. Same idea as both: learn
from posts that actually performed in a niche, then write in that register.

Its corpus is **imported rather than crawled**, and that is structural. Judging a
Tumblr post as high-engagement needs the author's own baseline, because Tumblr
publishes no follower count for blogs you do not control — an API key does not
change that. Computing that baseline costs a page of API calls *per blog*, so the
crawl lives in a separate collector that walks Tumblr's sitemaps at one request
per second over days, and this app reads its output. The corpus file is opened
read-only, so an import cannot disturb a collector that is still running.

**Tumblr brings its own niches.** Matching the corpus against the niche list the
other two tools share produced one match for "ai tools" out of 6,793 posts — not
because the corpus was thin, but because those are not the topics Tumblr is
organised around. It classifies into twenty that genuinely are: `art_design`,
`books_writing`, `lgbtq_community`, `fashion_beauty`, `humor_memes`, `anime_manga`,
`science_space` and more. Those stay out of the shared niche list, so they never
appear empty in the Bluesky and Mastodon dropdowns.

**Honest about its numbers.** Tumblr publishes one "notes" total — likes, reblogs
and replies summed, never broken down — so that is what is stored, rather than a
three-way split invented to fill the columns. Ranking divides by the blog's own
median note count and the app never calls that "followers".

**It learns from what you publish.** Paste a link into "I published this" and the
tool re-reads that post's notes at 1h, 24h and 48h, then rebuilds the pool. Your
best qualifying post holds a reserved slot, because the corpus arrived
pre-filtered to viral posts and nothing of yours would otherwise ever out-score
it.

## Engage: Tumblr tab

Your Tumblr dashboard and activity, in the app. It reblogs — with or without a
comment — rather than replying, because that is what Tumblr's API can do and how
conversation there actually works, and it treats tags as a real field, because on
Tumblr tags are the distribution. Setup takes four values rather than one, since
its API is OAuth 1.0a; the README says where each comes from.

## Adding a niche now fills it

Creating a niche used to write a row and stop there, leaving both generators
reading an empty corpus for six to twelve hours while generation quietly fell back
to platform norms. Both tools are now filled at once, from one place, because a
niche is a single shared object. The panel shows progress instead of a misleading
"0 posts · 0 exemplars".

## Fixes

All found by measuring the live corpus rather than reading the code.

- **41 of 187 Mastodon exemplars had zero engagement** — 10 of the 15 in one niche.
  The pool took the top N with no floor, which is fine while a niche has more
  measured posts than slots and silently wrong once it has fewer. The generator was
  being shown posts that demonstrably did not work.
- **Mastodon's ranking favoured whoever had fewest followers.** Posts with 5–23
  interactions from 52–205 followers outranked one with 158 interactions from
  1,924. A prior is now added to the denominator; the stored measurement is
  unchanged and still comparable with Bluesky's.
- **Hashtag walls were being taught as writing.** They clear an engagement floor
  easily, since tag spam is engagement bait and it works.
- **The hourly Mastodon job never learned from your own posts.** It wrote the
  measurements and then called a function with the wrong number of arguments; the
  error was swallowed by a catch-all.
- **The Bluesky cold start left new niches empty.** Its 48-hour backfill ran across
  every niche at once, capped at 500 and unordered, so a new niche's handful of
  posts never made the cut. Every niche added on a stocked install has been hitting
  this.

Net effect on the Mastodon pools: zero-engagement exemplars 41 → 0, tag walls
6 → 0, mean interactions per exemplar 6.9 → 10.0.

## Health monitor

Now separates proving the app works from paying to generate something. The daily
run exercises every module and capability without spending inference: endpoints
that have nothing to GET are held to their request contract instead — the probe
sends a body the request model must reject and requires a rejection back, so
nothing is generated and no token is spent, while still proving the router loaded
and its request model is intact.

## Upgrading

Nothing to migrate.

- Open the **Tumblr Post Creator** and press **Import** once — nothing is imported
  until you ask.
- **Mastodon pools rebuild themselves** on the next collection, so the corrected
  ranking arrives within twelve hours, or immediately if you press Collect.
