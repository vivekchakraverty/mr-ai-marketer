The Keyword Surfer collector arrived in 0.6.0 with one thing missing: the plan could not use
what it collected. This closes that gap.

## A collected run can be the basis of a plan

The Marketing Plan brief has a new **Keyword data** dropdown listing your finished Keyword
Surfer runs. Pick one and the SEO plan is built on those figures instead of whatever the free
tiers could estimate — previously the real volumes sat one screen away from the section that
needed them most.

**Google Ads still wins.** An attached run is used *only* when the official tier returns
nothing, so it never overrides measured figures:

| | Source | Used when |
|---|---|---|
| 1 | Google Ads API | Credentials configured and the call succeeds |
| 2 | **Your attached Surfer run** | Google Ads returned nothing |
| 3 | Autocomplete + Trends | Neither of the above |
| 4 | LLM estimate | Nothing else answered |

A run that has since been deleted is ignored rather than refused — the plan falls back to
researching its own keywords, exactly as before.

## The plan is planned around the numbers, not just given them

Related keywords used to reach the SEO stage as a bare list of names, throwing away every
figure Surfer collects for them — volume, CPC, and how similar each idea is to its seed — at
the point it mattered.

They now arrive with their figures intact, and the SEO stage is told what to do with them:
**cluster by similarity**, **order the 90-day calendar by volume**, and **read CPC as
commercial intent** — a term people pay a lot per click for earns a landing page, a cheap
informational one earns a blog post.

Each cluster now reports its summed monthly volume and names its highest-volume term, so the
plan can be checked against the data it was built from rather than taken on trust. Verified
against a real collection: cluster totals of 25,800 and 4,200 matching their inputs exactly,
landing pages on the high-CPC transactional terms, calendar sequenced by volume.

## Paid ads use collected CPC when Google Ads has none

The ads plan's per-keyword Search CPC block used Google Ads figures or fell back to a generic
industry benchmark. Collected per-keyword CPC now sits in between — this product's actual
keywords beat an industry average. It is labelled as the different thing it is, with an
instruction to leave headroom, rather than passed off as auction data.

## Upgrading

Nothing to migrate. With no Keyword Surfer runs the dropdown reads *Research keywords
automatically* and the tool behaves exactly as it did in 0.6.0.

## Installing

The Windows installer is **unsigned**, so SmartScreen will warn on first run: choose
*More info → Run anyway*. macOS and Linux artifacts are attached below.
