# Mr. AI Marketer 1.1.0

This update fixes scheduled Mastodon and Bluesky posts stopping silently when your cloud poster Space is paused, and makes that state visible and repairable from the app.

## What's new since v1.0.1

- **A paused Space is now reported as paused:** A Space on free Hugging Face hardware normally goes to sleep, and a sleeping Space wakes up the next time anything touches it, posts everything that was due, and needs no attention. A *paused* Space behaves nothing like that: it refuses every request and never starts on its own, so scheduled posts stop. Both look identical from outside, and the app used to describe either as "asleep or waking" and tell you that queued posts would go out when it woke. It now checks which one it is and says so.
- **Restart this Space:** Settings → Cloud posting shows a **Restart this Space** button when your Space is paused or has crashed. This needs the Hugging Face token in Settings, which is the one that can act on your account — the token your Space holds is limited to your outbox and cannot restart anything. Everything that came due while the Space was down goes out on its first pass afterwards, once each.
- **The Space watcher now watches the poster Space, and fixes it:** The tray watcher checked the Spaces that generate content but never the one that posts, so the one component nobody opens by hand was also the one nothing was keeping an eye on. It now includes your poster Space, is told which Space that is by the app rather than needing to be configured by hand, and restarts a paused or crashed Space instead of only mentioning it. Automatic restarting can be turned off with `"restartBroken": false` in `healthmon.json`. A paused Space is also reported as a failure rather than a warning, for every Space the watcher follows.
- **Clearer heartbeat failures:** The optional GitHub Actions heartbeat now explains that a Space is paused, and that pinging cannot recover it, instead of only reporting that the Space could not be reached. Set the repository variable `POSTER_SPACE_ID` to your Space's `owner/name` to turn this on.

## If your scheduled posts have stopped

Open Settings → Cloud posting and choose **Check now**. If it reports the Space as paused, use **Restart this Space**. Nothing in the queue is lost while a Space is down, and nothing is sent twice when it comes back — each post is tied to its own identifier on both networks, so a late send cannot become a duplicate.

If you are updating from an earlier version, your Space is still running the poster code from the version that created it. Use Settings → Cloud posting → **Reconnect credentials** → **Repair this Space** to bring it up to date, then restart it.

## Install and feedback

Download the asset for your operating system below. Windows 10/11 x64 is the primary supported desktop target; macOS and Linux packages are experimental. The installers are unsigned, so Windows SmartScreen or macOS Gatekeeper may show a warning. Review the publisher and release URL before choosing to run one.

Please report problems through [GitHub Issues](https://github.com/vivekchakraverty/mr-ai-marketer/issues), including your operating system, workspace, the tool involved, and steps to reproduce.
