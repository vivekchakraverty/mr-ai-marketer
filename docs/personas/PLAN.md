# Audience Personas plan

1. **M1 Interview:** versioned question data, generic accessible form, autosaved named runs and Quick/Full modes.
2. **M2 Research plan:** deterministic keywords and editable source/query plan; explicit approval before collection.
3. **M3 Collection:** cancellable persisted job; offline demo and CSV; consent-gated official/public sources with per-source status.
4. **M4 Analysis:** anonymize, dedupe, tag and segment evidence; evidence-linked candidates and honest confidence.
5. **M5 Review:** score, rename, merge and edit candidates, then reconcile final personas.
6. **M6 Personas:** evidence drawer, method and validation plan, export, refresh, delete and integration helper.

After each milestone, run focused tests and commit only new persona files and intentional integration edits. Full backend tests and frontend typecheck follow M6.
