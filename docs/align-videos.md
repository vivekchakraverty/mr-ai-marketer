# Align → Videos: public Viral Footprint

The Videos subtab searches public YouTube videos, downloads a bounded set of candidate clips, and compares their footage with an uploaded reel. It uses the app's existing `ytsearch`/yt-dlp integration. No ViralMint server, Google API key, or new dependency is needed. Enter distinctive caption words or a phrase with the upload. If those are blank, local Whisper speech transcription can supply the query when the reel has speech. Public services cannot search every video by its visual fingerprint, so a missed result means only that no verified match was found among the returned search candidates.

Topic queries run both YouTube's short-video duration filter and a regular search, combining up to 40 distinct hits. Clips up to three minutes are eligible for short uploads; longer uploads allow references up to 1.5 times their duration, capped at ten minutes. Duration closeness ranks the candidates rather than rejecting shorter edits. Up to 12 are visually checked. Enter a public YouTube watch, Shorts, or youtu.be URL in the optional direct-comparison field to prioritize a known public version, with or without a keyword search.

Every checked clip appears in the footage comparisons, including clips below the copy threshold. The reference-view benchmark describes current views in the eligible search sample. Those counters belong to the public reference posts. They do not predict the uploaded reel's future reach. Content virality is only measured when at least one copy is verified and view metrics exist; otherwise the report says **Virality not established**. Saved no-copy reports that previously displayed zero are corrected when reopened.

**Supported search:** YouTube only. TikTok, Douyin, Instagram, and Reddit video search are unavailable in this mode. YouTube may block or rate limit search, metadata, captions, or media downloads. The report shows the query, number of results, duration-filtered candidates, checked clips, and download errors. If no candidate can be checked, the job fails with a clear message instead of reporting “no match.”

The endpoints are `GET /align/videos/source`, `POST /align/videos/analyze` (multipart `file`, optional `search_terms` and `reference_url`, 200 MB upload maximum), and `GET /align/videos/{analysis_id}`. Analysis runs as a bounded background job. Uploaded originals and temporary candidate downloads are deleted after analysis. The local SQLite database retains job status, media metadata, fingerprints, and reports. Reports survive app restarts; interrupted jobs are marked failed and can be retried. Starting another job cancels polling of the previous report, so a late response cannot replace the new result.

FFmpeg extracts metadata and five frames from the upload and each candidate. Each frame gets a 64-bit difference hash and low-resolution luminance signature from both the whole image and a center crop. Adjacent frame positions are compared to tolerate small trims. SHA-256 only identifies byte-identical clips. Visual, transcript, and duration similarities are weighted 0.65, 0.25, and 0.10 when available. Missing transcript weight is redistributed, and a minimum visual threshold prevents text or duration alone from verifying a copy. Thresholds and weights live in `backend/app/services/viral_footprint/scoring.py`.

Whisper uses the existing Docu Maker `faster-whisper` dependency and may download a model on first use. It runs when search terms and the direct URL are blank, or when `MRAIM_VIRAL_FOOTPRINT_TRANSCRIBE=1` is set. Set that variable to `0` to disable it. Public YouTube metadata may include current views, likes, and comments. Per-post virality and creator outlier scores are blank because search does not establish a creator baseline. The separate content score is a 0–100 heuristic based on observed views (up to 38 points), copy count (26), platform count (26), and any available outlier (10). Summed views are post counters, not unique viewers or proven cross-platform reach.

From `backend`, run `.\.venv\Scripts\python.exe -m unittest tests.test_viral_footprint -v`. From `electron`, run `node scripts/verify-align-videos.mjs` and `npm run typecheck`.
