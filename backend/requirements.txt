# Direct dependencies, pinned.
#
# Every version here is the one this app is actually tested against — captured from a working
# environment, not chosen from a changelog. Ranges (`>=`) were the previous style and they
# cost more than they gave:
#
#   * two installs a week apart got different libraries, so "works on my machine" was
#     literally true and useless;
#   * a vulnerability scanner reads `>=` and resolves nothing, so `trivy fs` reported a clean
#     Python bill of health that was pure artifact — 16 real findings were invisible until the
#     installed set was scanned directly.
#
# Transitive dependencies are pinned separately in requirements.lock.txt. Install from this
# file to develop, from the lock to reproduce a build exactly.
#
# To move a pin: change it here, reinstall, run the app, then regenerate the lock with
#   python -m pip freeze --exclude-editable > requirements.lock.txt

# --- Security floors ------------------------------------------------------------
